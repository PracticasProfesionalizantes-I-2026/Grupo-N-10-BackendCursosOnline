# 📌 Descripción del Proyecto

Este proyecto consiste en el desarrollo de una plataforma LMS (*Learning Management System*) orientada a la gestión integral de cursos online.

El sistema busca centralizar y optimizar procesos educativos que actualmente suelen manejarse mediante herramientas dispersas como:

- correos electrónicos,
- formularios,
- planillas,
- mensajes privados,
- y sistemas no integrados.

La propuesta apunta a construir una solución moderna, organizada y escalable, permitiendo administrar usuarios, cursos, inscripciones y seguimiento académico desde una única plataforma.

---

# 🎯 Objetivos del Sistema

El sistema permitirá:

- Gestionar usuarios mediante registro e inicio de sesión.
- Administrar cursos y contenidos.
- Gestionar inscripciones de alumnos.
- Controlar accesos según roles.
- Realizar seguimiento del progreso académico.
- Centralizar información educativa.
- Mejorar la organización administrativa.
- Facilitar futuras ampliaciones del sistema.

---

# 🧠 Roles del Sistema

La plataforma contará inicialmente con los siguientes roles:

## 👨‍💼 Administrador
- Gestión completa del sistema.
- Administración de usuarios.
- Administración de cursos.
- Control general de la plataforma.

## 👨‍🏫 Profesor
- Gestión de cursos asignados.
- Seguimiento de alumnos.
- Administración de contenidos.

## 👨‍🎓 Alumno
- Registro e inicio de sesión.
- Inscripción a cursos.
- Visualización de progreso.
- Acceso a contenidos.

# 🧩 Problemática Detectada

Actualmente muchas instituciones o proyectos educativos pequeños presentan problemas como:

- Información desorganizada.
- Procesos manuales.
- Falta de control centralizado.
- Dificultad para gestionar alumnos.
- Escasa escalabilidad.
- Herramientas separadas entre sí.

Este proyecto busca resolver dichas problemáticas mediante una arquitectura sólida y una plataforma unificada.
