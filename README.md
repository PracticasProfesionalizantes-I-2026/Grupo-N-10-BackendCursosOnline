# 📌 Descripción
Este proyecto consiste en el desarrollo de un backend para una plataforma de cursos online (LMS).

El objetivo es centralizar la gestión de cursos, usuarios e inscripciones, reemplazando el uso de herramientas dispersas como correos, planillas o formularios, y proporcionando una base sólida para futuras aplicaciones web

# 🎯 Objetivo del sistema
Desarrollar un sistema backend que permita:
- Gestionar usuarios (registro e inicio de sesión)
- Administrar cursos
- Permitir la inscripción de alumnos
- Llevar el seguimiento del progreso
- Controlar accesos según roles (admin, profesor, alumno)

# 🧠 Funcionalidades principales (MVP)
En esta primera etapa se implementarán:
- Registro y autenticación de usuarios
- Asignación de roles
- Creación, edición y eliminación de cursos
- Inscripción a cursos
- Consulta del progreso del alumno

# 📊 Problema que resuelve
Actualmente, muchas plataformas educativas pequeñas no cuentan con un sistema centralizado, lo que genera:
- Información dispersa
- Falta de control sobre inscripciones
- Procesos manuales ineficientes
- Dificultad para escalar el sistema
Este proyecto busca solucionar estos problemas mediante una arquitectura organizada y escalable.
