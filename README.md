# 🎓 Lumen — Sistema de Gestión de Cursos Online

Lumen es un proyecto académico orientado a la gestión de cursos online, desarrollado como parte de la materia **Práctica Profesionalizante I**.

El proyecto busca representar de forma clara los principales procesos relacionados con la gestión de cursos, usuarios e inscripciones.

## Backend .NET 10

El backend se encuentra en **4-Codigo** e implementa los 16 casos de uso mediante una API REST con arquitectura N-Tier, SQLite, JWT, OpenAPI/Scalar y pruebas automatizadas.

**[Instalar, configurar, compilar, ejecutar y probar el backend](4-Codigo/README.md)**

La guía especifica el SDK requerido, la configuración externa de JWT, las migraciones y la inicialización por entorno. También enlaza la colección Bruno y su recorrido reproducible de 19 requests en `00-Exposicion`.

## 🖥️ Prototipo

Lumen cuenta actualmente con un prototipo frontend funcional y navegable que permite recorrer las principales pantallas y flujos definidos para el sistema.

El prototipo utiliza datos locales y se ejecuta de forma independiente del backend. Su integración con la API no forma parte de esta entrega.

[Acceder al prototipo de Lumen](https://lumen-bay-phi.vercel.app)
